FreeIndustry prototype art samples

Top-down orthographic sample sprites and floor textures.

These are concept-art crops for rapid PixiJS prototyping, NOT dimension-accurate or seam-tested game assets.
Machine and person images have approximate transparent cutouts and may need manual cleanup.
Use millimeter dimensions from the game data to determine rendered sprite size; 500mm floor construction grid.
Tile images are 256x256 PNG, but some include a multi-cell decorative pattern.
To tile seamlessly in production, repaint or use proper seamless textures.
Overlay images are examples only; calculate access zones from the machine definitions.
